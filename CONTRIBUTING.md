# Contributing

Thanks for your interest in contributing!

## Development Setup
1. Install MySQL 8.x and Node 18+.
2. Run the SQL scripts in `database/` (see README).
3. Start the backend (`backend/`) and frontend (`frontend/`).

## Branching
- `main`: stable
- `feat/<name>`: new features
- `fix/<name>`: bug fixes

## Conventional Commits
Use this format:
- `feat: ...`
- `fix: ...`
- `docs: ...`
- `chore: ...`
- `refactor: ...`

## Pull Requests
- Link issues with `Closes #<id>`.
- Keep PRs focused and under 300 lines when possible.
- Add screenshots for UI changes.
